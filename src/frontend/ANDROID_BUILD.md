# Android APK Build Instructions

This document explains how to build an Android APK for **Adarsh Mens Tailors** from a clean checkout.

## Prerequisites

Before building, ensure you have the following installed:

1. **Node.js** (v18 or higher) and **pnpm**
2. **Java Development Kit (JDK)** 17 or higher
   - Set `JAVA_HOME` environment variable
3. **Android Studio** or **Android SDK Command-line Tools**
   - Android SDK Platform 34
   - Android SDK Build-Tools 34.0.0
   - Set `ANDROID_HOME` or `ANDROID_SDK_ROOT` environment variable
4. **Capacitor CLI** (installed via project dependencies)
